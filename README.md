# Parcours Visuel — Cabinet d'orthoptie

Ce dépôt contient deux choses distinctes :

- **`index.html`** — l'écran d'affichage de salle d'attente (slideshow plein écran, format 1080×1920) avec la vidéo `clip.mp4`.
- **`site/index.html`** — le site web vitrine du cabinet, élégant et minimaliste, en une seule page responsive (accueil, présentation, prestations, équipe, infos pratiques, contact).

## Personnaliser le site (`site/index.html`)

Quelques éléments sont volontairement en placeholder, à remplacer avant mise en ligne :

- Adresse, téléphone, email et horaires (section « Infos pratiques » et pied de page).
- Lien de prise de rendez-vous en ligne (Doctolib ou équivalent) — actuellement `href="#"`.
- Noms, rôles et bios de l'équipe (section « Équipe »).

Le site ne dépend d'aucun outil de build : il suffit d'ouvrir `site/index.html` dans un navigateur, ou de le servir statiquement (GitHub Pages, etc.).
